# MK-02 --- Landing Page

**Versão:** 1.0\
**Status:** Approved\
**Documento:** `MK-02_LANDING_PAGE.md`

------------------------------------------------------------------------

# 1. Objetivo

Definir a estratégia, arquitetura e requisitos da Landing Page oficial
do **BORAH**, com foco na conversão de visitantes em usuários
cadastrados na lista de espera e futuros usuários do aplicativo.

------------------------------------------------------------------------

# 2. Escopo

Aplica-se a:

-   Website oficial
-   Landing Page de pré-lançamento
-   Campanhas de mídia paga
-   Tráfego orgânico
-   SEO
-   Analytics

------------------------------------------------------------------------

# 3. Objetivos

-   Gerar reconhecimento da marca
-   Capturar leads qualificados
-   Validar interesse pelo produto
-   Direcionar tráfego para as lojas de aplicativos após o lançamento
-   Apoiar campanhas de marketing

------------------------------------------------------------------------

# 4. Estrutura da Página

## Hero Section

-   Logo do BORAH
-   Headline principal
-   Subtítulo
-   CTA principal
-   Mockup do aplicativo

## Benefícios

-   Descoberta de restaurantes
-   Rankings entre amigos
-   Gamificação
-   Avaliações sociais

## Como Funciona

1.  Crie sua conta
2.  Convide seus amigos
3.  Descubra restaurantes
4.  Avalie experiências
5.  Suba no ranking

## Prova Social

-   Depoimentos (quando disponíveis)
-   Números relevantes
-   Parceiros

## FAQ

Responder às principais dúvidas.

## Rodapé

-   Política de Privacidade
-   Termos de Uso
-   Contato
-   Redes sociais

------------------------------------------------------------------------

# 5. Call to Action (CTA)

CTAs principais:

-   Entrar na lista de espera
-   Baixar o aplicativo (após lançamento)
-   Conhecer o BORAH

------------------------------------------------------------------------

# 6. SEO

Implementar:

-   Meta Title
-   Meta Description
-   Open Graph
-   Schema.org
-   Sitemap
-   Robots.txt
-   URLs amigáveis

------------------------------------------------------------------------

# 7. Analytics

Configurar:

-   Google Analytics 4
-   Google Tag Manager
-   Meta Pixel
-   Eventos de conversão
-   Scroll depth
-   Cliques em CTA

------------------------------------------------------------------------

# 8. Performance

Metas:

-   LCP \< 2,5 s
-   CLS \< 0,1
-   INP dentro das recomendações
-   Lighthouse \> 90

------------------------------------------------------------------------

# 9. Responsividade

Compatibilidade com:

-   Desktop
-   Tablet
-   Smartphones Android
-   iPhone

------------------------------------------------------------------------

# 10. Integrações

-   Lista de espera
-   CRM
-   E-mail marketing
-   Formulários
-   Redes sociais

------------------------------------------------------------------------

# 11. Ferramentas

-   Next.js ou Astro
-   Cloudflare Pages ou Vercel
-   Google Analytics 4
-   Google Search Console
-   Meta Pixel
-   Hotjar (opcional)

------------------------------------------------------------------------

# 12. KPIs

-   Visitantes
-   Conversão
-   Leads captados
-   CTR dos CTAs
-   Bounce Rate
-   Tempo médio na página

------------------------------------------------------------------------

# 13. Boas Práticas

-   CTA acima da dobra
-   Mensagem objetiva
-   Layout limpo
-   Otimização para dispositivos móveis
-   Testes A/B contínuos

------------------------------------------------------------------------

# 14. Anti-patterns

Evitar:

-   Página lenta
-   Excesso de informações
-   Formulários longos
-   CTAs pouco visíveis
-   Imagens pesadas

------------------------------------------------------------------------

# 15. Checklist

-   Estrutura aprovada
-   SEO configurado
-   Analytics instalado
-   Pixel configurado
-   Responsividade validada
-   Performance aprovada
-   Formulário integrado

------------------------------------------------------------------------

# 16. Critérios de Aceite

-   Landing Page publicada
-   Conversões mensuráveis
-   Ferramentas de análise funcionando
-   Performance aprovada
-   SEO implementado
