# MK-03 --- Waitlist Strategy

**Versão:** 1.0\
**Status:** Approved\
**Documento:** `MK-03_WAITLIST_STRATEGY.md`

------------------------------------------------------------------------

# 1. Objetivo

Definir a estratégia da lista de espera (Waitlist) do **BORAH**,
maximizando a geração de leads qualificados, criando expectativa para o
lançamento e incentivando o crescimento orgânico por meio de indicações.

------------------------------------------------------------------------

# 2. Escopo

Aplica-se a:

-   Landing Page
-   Website oficial
-   Aplicativo
-   CRM
-   E-mail Marketing
-   Programa de Indicação

------------------------------------------------------------------------

# 3. Objetivos

-   Captar usuários antes do lançamento
-   Validar demanda
-   Construir comunidade
-   Incentivar compartilhamentos
-   Preparar a base para o lançamento

------------------------------------------------------------------------

# 4. Jornada do Usuário

1.  Acessa a Landing Page
2.  Conhece o BORAH
3.  Entra na lista de espera
4.  Confirma o e-mail
5.  Recebe comunicações periódicas
6.  Convida amigos
7.  Recebe acesso antecipado
8.  Instala o aplicativo

------------------------------------------------------------------------

# 5. Estrutura da Waitlist

Coletar:

-   Nome
-   E-mail
-   Cidade (opcional)
-   Origem do cadastro
-   Código de indicação (quando aplicável)

------------------------------------------------------------------------

# 6. Programa de Indicação

Cada usuário recebe um link exclusivo.

Benefícios possíveis:

-   Prioridade no acesso
-   Badges exclusivos
-   Benefícios no lançamento
-   Convites extras

------------------------------------------------------------------------

# 7. Comunicação

Fluxo sugerido:

-   E-mail de boas-vindas
-   Confirmação de cadastro
-   Atualizações do desenvolvimento
-   Convite para o lançamento
-   Liberação de acesso

------------------------------------------------------------------------

# 8. Automação

Automatizar:

-   Confirmação de cadastro
-   Segmentação de usuários
-   Disparo de campanhas
-   Ranking de indicações
-   Recuperação de leads inativos

------------------------------------------------------------------------

# 9. KPIs

-   Visitantes
-   Conversão da Landing Page
-   Leads captados
-   Taxa de confirmação
-   Convites enviados
-   Indicações por usuário
-   CAC
-   Custo por Lead (CPL)

------------------------------------------------------------------------

# 10. Ferramentas

-   CRM
-   E-mail Marketing
-   Google Analytics 4
-   Meta Pixel
-   Firebase Analytics
-   Sistema de Referral

------------------------------------------------------------------------

# 11. Boas Práticas

-   Formulário simples
-   Comunicação frequente
-   Benefícios claros
-   Incentivos à indicação
-   Mensuração contínua

------------------------------------------------------------------------

# 12. Anti-patterns

Evitar:

-   Formulários extensos
-   Spam de e-mails
-   Benefícios confusos
-   Falta de acompanhamento
-   Ausência de métricas

------------------------------------------------------------------------

# 13. Checklist

-   Landing Page integrada
-   CRM configurado
-   Fluxo de e-mails criado
-   Referral Program implementado
-   Analytics configurado
-   KPIs definidos

------------------------------------------------------------------------

# 14. Critérios de Aceite

-   Waitlist publicada
-   Fluxos automatizados
-   Captação de leads funcionando
-   Programa de indicação ativo
-   Métricas disponíveis

------------------------------------------------------------------------

# 15. Evolução prevista (Versão 2.0)

-   Gamificação da lista de espera
-   Ranking em tempo real
-   Convites por níveis
-   Missões para desbloqueio de benefícios
-   Segmentação inteligente baseada em IA
