# PB-03 --- Google Play Store Assets

**Versão:** 1.0\
**Status:** Approved\
**Documento:** `PB-03_GOOGLE_PLAY_STORE_ASSETS.md`

------------------------------------------------------------------------

# 1. Objetivo

Definir todos os materiais gráficos, textuais e de marketing necessários
para a publicação e manutenção do BORAH na Google Play Store,
assegurando conformidade com as diretrizes da Google e uma apresentação
consistente da marca.

# 2. Escopo

Aplica-se a:

-   Google Play Console
-   Página pública do aplicativo
-   Materiais promocionais
-   Localização (i18n)

# 3. Assets Obrigatórios

## Ícone

-   512 × 512 px
-   PNG
-   Fundo transparente (quando aplicável)

## Feature Graphic

-   1024 × 500 px
-   Destaque da marca
-   Sem excesso de texto

## Screenshots

Obrigatórios para:

-   Smartphone
-   Tablet (recomendado)

Diretrizes:

-   Alta resolução
-   Interface real
-   Fluxos principais
-   Legendas curtas destacando benefícios

## Vídeo Promocional (Opcional)

-   Link do YouTube
-   Demonstração das principais funcionalidades
-   Duração recomendada: 30--90 segundos

# 4. Conteúdo da Loja

## Nome do App

BORAH

## Short Description

Até 80 caracteres, destacando a proposta de valor.

## Full Description

Até 4.000 caracteres contendo:

-   Visão geral
-   Principais funcionalidades
-   Benefícios
-   Recursos
-   Contato e suporte

# 5. Categoria

-   Categoria principal
-   Tags relevantes
-   Classificação etária adequada

# 6. Localização

Preparar textos para:

-   Português (Brasil)
-   Inglês

# 7. Política de Qualidade

Todos os assets devem:

-   Representar funcionalidades reais
-   Estar atualizados
-   Respeitar o Design System
-   Não conter informações enganosas

# 8. Ferramentas

-   Google Play Console
-   Figma
-   Canva (apoio)
-   Adobe Illustrator (opcional)

# 9. Checklist

-   Ícone 512x512
-   Feature Graphic
-   Screenshots
-   Short Description
-   Full Description
-   Categoria
-   Tags
-   Classificação indicativa
-   Localização
-   Vídeo promocional (opcional)

# 10. Boas Práticas

-   Atualizar screenshots a cada grande release
-   Evidenciar benefícios antes de funcionalidades
-   Usar linguagem clara
-   Manter consistência visual

# 11. Anti-patterns

Evitar:

-   Capturas desatualizadas
-   Texto excessivo nas imagens
-   Promessas não implementadas
-   Assets de baixa qualidade

# 12. Critérios de Aceite

-   Todos os assets obrigatórios produzidos
-   Conteúdo revisado
-   Compatível com os requisitos da Google Play
-   Branding consistente

# 13. Evolução prevista (Versão 2.0)

-   Assets localizados por idioma
-   A/B Testing de Store Listing
-   Custom Store Listings
-   Seasonal Store Assets
-   Integração com campanhas de marketing
