# PB-04 --- Privacy & Legal

**Versão:** 1.0\
**Status:** Approved\
**Documento:** `PB-04_PRIVACY_AND_LEGAL.md`

------------------------------------------------------------------------

# 1. Objetivo

Definir os requisitos legais, políticas de privacidade e termos de uso
do BORAH, garantindo conformidade com a LGPD, Google Play, App Store e
demais regulamentações aplicáveis.

------------------------------------------------------------------------

# 2. Escopo

Aplica-se a:

-   Aplicativo Android
-   Aplicativo iOS
-   Website
-   APIs
-   Banco de Dados
-   Serviços de autenticação
-   Serviços de terceiros

------------------------------------------------------------------------

# 3. Base Legal

A documentação deverá estar alinhada com:

-   Lei Geral de Proteção de Dados (LGPD)
-   Google Play Developer Program Policies
-   Apple App Store Review Guidelines
-   Marco Civil da Internet
-   Regulamentos de proteção de dados aplicáveis

------------------------------------------------------------------------

# 4. Política de Privacidade

A Política de Privacidade deverá informar:

-   Dados coletados
-   Finalidade da coleta
-   Base legal do tratamento
-   Tempo de retenção
-   Compartilhamento de dados
-   Direitos do usuário
-   Contato do responsável
-   Processo para exclusão de conta e dados

------------------------------------------------------------------------

# 5. Termos de Uso

Os Termos de Uso deverão definir:

-   Aceitação dos termos
-   Elegibilidade
-   Regras de utilização
-   Conteúdo gerado pelos usuários
-   Condutas proibidas
-   Suspensão e encerramento de contas
-   Limitação de responsabilidade
-   Alterações dos termos

------------------------------------------------------------------------

# 6. Consentimento

Implementar mecanismos para:

-   Aceite da Política de Privacidade
-   Aceite dos Termos de Uso
-   Registro de data e versão aceita
-   Atualização de consentimentos quando necessário

------------------------------------------------------------------------

# 7. Direitos do Usuário

Disponibilizar meios para:

-   Acesso aos dados
-   Correção de dados
-   Portabilidade
-   Exclusão da conta
-   Revogação do consentimento

------------------------------------------------------------------------

# 8. Compartilhamento de Dados

Documentar:

-   Serviços utilizados
-   Finalidade do compartilhamento
-   Medidas de segurança
-   Dados compartilhados
-   Base legal

------------------------------------------------------------------------

# 9. Segurança da Informação

Adotar:

-   Criptografia em trânsito
-   Criptografia em repouso
-   Controle de acesso
-   Logs de auditoria
-   Backup
-   Monitoramento

------------------------------------------------------------------------

# 10. Exclusão de Conta

O aplicativo deverá permitir:

-   Solicitação de exclusão
-   Exclusão lógica ou física conforme política
-   Confirmação ao usuário
-   Prazo para processamento
-   Exclusão de dados vinculados quando aplicável

------------------------------------------------------------------------

# 11. Contatos Oficiais

Disponibilizar:

-   E-mail de suporte
-   Canal para solicitações LGPD
-   Página da Política de Privacidade
-   Página dos Termos de Uso

------------------------------------------------------------------------

# 12. Ferramentas

-   Google Play Console
-   App Store Connect
-   Supabase
-   GitHub
-   Sistema de atendimento ao usuário

------------------------------------------------------------------------

# 13. Checklist

-   Política de Privacidade publicada
-   Termos de Uso publicados
-   Fluxo de aceite implementado
-   Exclusão de conta disponível
-   Canal LGPD informado
-   Links configurados nas lojas

------------------------------------------------------------------------

# 14. Boas Práticas

-   Linguagem clara
-   Revisão jurídica periódica
-   Transparência sobre coleta de dados
-   Versionamento dos documentos
-   Registro dos consentimentos

------------------------------------------------------------------------

# 15. Anti-patterns

Evitar:

-   Coleta excessiva de dados
-   Consentimentos implícitos
-   Políticas desatualizadas
-   Falta de canal para exclusão
-   Compartilhamento não documentado

------------------------------------------------------------------------

# 16. Critérios de Aceite

-   Política publicada
-   Termos publicados
-   Conformidade com LGPD
-   Links disponíveis na Play Store e App Store
-   Fluxos legais implementados

------------------------------------------------------------------------

# 17. Evolução prevista (Versão 2.0)

Planejar suporte para:

-   Centro de Privacidade no aplicativo
-   Gestão granular de consentimentos
-   Exportação automática de dados
-   Auditoria de consentimentos
-   Adequação a novas regulamentações internacionais
