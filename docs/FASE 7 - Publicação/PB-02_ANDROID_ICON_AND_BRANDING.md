# PB-02 --- Android Icon & Branding

**Versão:** 1.0\
**Status:** Approved\
**Documento:** `PB-02_ANDROID_ICON_AND_BRANDING.md`

------------------------------------------------------------------------

# 1. Objetivo

Definir os padrões de identidade visual do aplicativo Android do BORAH,
garantindo consistência entre o aplicativo, a Google Play Store e todos
os materiais de divulgação.

# 2. Escopo

Aplica-se a:

-   Ícone do aplicativo
-   Splash Screen
-   Cores
-   Tipografia
-   Branding
-   Assets gráficos
-   Modos claro e escuro

# 3. Identidade Visual

-   Nome: **BORAH**
-   Identidade consistente com o Design System
-   Uso exclusivo da identidade oficial

# 4. Ícone do Aplicativo

## Adaptive Icon

-   Foreground separado
-   Background sólido
-   Compatível com Android 8+

## Legacy Icon

-   Compatível com versões anteriores

## Monochrome Icon

-   Obrigatório para Android 13+

Diretrizes:

-   Design simples
-   Alta legibilidade
-   Sem textos
-   Sem bordas artificiais

# 5. Splash Screen

Seguir a Splash Screen API do Android.

Elementos:

-   Logo centralizada
-   Fundo institucional
-   Tempo mínimo de exibição
-   Transição suave para a tela inicial

# 6. Paleta de Cores

Documentar:

-   Cor primária
-   Cor secundária
-   Cor de destaque
-   Cores de sucesso, aviso e erro
-   Fundo claro e escuro

# 7. Tipografia

Padronizar:

-   Fonte oficial
-   Hierarquia de títulos
-   Escalas tipográficas
-   Espaçamentos

# 8. Assets

Organizar:

-   Logos (SVG/PNG)
-   Ícones
-   Ilustrações
-   Imagens institucionais
-   Favicons

# 9. Dark Mode

Garantir:

-   Contraste adequado
-   Ícones compatíveis
-   Cores adaptadas
-   Legibilidade

# 10. Consistência de Marca

Validar:

-   Nome do app
-   Ícone
-   Splash
-   Cores
-   Elementos gráficos

# 11. Ferramentas

-   Flutter Launcher Icons
-   Android Studio Asset Studio
-   Figma
-   Material Design

# 12. Critérios de Aprovação

-   Ícones gerados para todas as densidades
-   Splash validada
-   Branding consistente
-   Compatibilidade com Android 13+

# 13. Boas Práticas

-   Vetores sempre que possível
-   Margens de segurança
-   Arquivos-fonte versionados
-   Revisão antes de cada release

# 14. Anti-patterns

Evitar:

-   Texto no ícone
-   Baixo contraste
-   Logos distorcidas
-   Arquivos rasterizados de baixa qualidade

# 15. Checklist

-   Adaptive Icon
-   Legacy Icon
-   Monochrome Icon
-   Splash Screen
-   Paleta documentada
-   Tipografia definida
-   Assets organizados
-   Dark Mode validado

# 16. Critérios de Aceite

-   Identidade visual documentada
-   Assets aprovados
-   Branding consistente
-   Aplicativo pronto para publicação
