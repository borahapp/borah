# Marketing Kit — Especificações

**Contexto:** BETA-10E1. Especificações para materiais de divulgação além das lojas (redes sociais e kit de apresentação). Nenhuma imagem foi produzida. Toda peça deve seguir `design_system.md` — nenhuma variação de marca fora do já oficial.

---

## 1. Redes sociais — especificações por formato

| Plataforma | Formato | Dimensão | Uso recomendado |
|---|---|---|---|
| Instagram — Feed (quadrado) | 1:1 | 1080×1080px | Anúncio de lançamento, destaque de funcionalidade |
| Instagram — Feed (retrato) | 4:5 | 1080×1350px | Carrossel de funcionalidades (reaproveitar as 6 composições de `screenshots_spec.md`) |
| Instagram/TikTok — Stories e Reels | 9:16 | 1080×1920px | Vídeo vertical — o mesmo storyboard de `storyboard.md`, recortado/adaptado para vertical |
| LinkedIn — Post | 1.91:1 | 1200×628px | Comunicação institucional/técnica (ex.: anúncio de disponibilidade nas lojas) — tom mais sóbrio, mesma paleta |
| TikTok — Vídeo | 9:16 | 1080×1920px | Mesma lógica de Stories/Reels |
| Miniaturas (thumbnails) de vídeo | 16:9 | 1280×720px | Frame de capa para qualquer vídeo hospedado fora das lojas (YouTube, site) |

### Diretrizes comuns
- Símbolo/logo sempre com a área livre mínima já especificada em `app_icon.md` (metade da altura do símbolo).
- Overlay de texto: mesmo padrão tipográfico de `screenshots_spec.md` (Fredoka Bold para mensagem principal, Manrope para complemento).
- Cores: só as 3 cores de marca + os 2 gradientes oficiais — nenhuma cor nova introduzida para redes sociais.

---

## 2. Mockups

- **Dispositivo de referência**: iPhone (moldura minimalista, sem excesso de detalhe de hardware que distraia da tela) — mesmo princípio de "baixa competição visual" do Manual da Marca.
- **Ângulo**: preferencialmente frontal ou levemente inclinado (~10-15°) — nunca perspectivas extremas que dificultem a leitura da tela.
- **Fundo do mockup**: Gradiente Roxo oficial ou Preto Uva sólido — mesma paleta de `screenshots_spec.md`.

## 3. Banners

- Usar a mesma composição de layout da Feature Graphic (`feature_graphic.md`) como base — símbolo + tagline de um lado, tela real do outro — adaptando a proporção conforme o canal (ex.: banner de site, banner de e-mail).

## 4. Assinatura visual (para e-mails, apresentações, documentos)

- Logo horizontal oficial (`borah_logo_white` sobre fundo escuro/gradiente, ou `borah_logo_black` sobre fundo claro) + nome do responsável + link do site institucional (`docs/release/hosting.md`) uma vez publicado.
- Nunca usar o símbolo isolado como assinatura de e-mail — a assinatura deve sempre ter a logo horizontal completa, para reforçar reconhecimento de marca em contextos de texto corrido.

## 5. Capa de apresentação (institucional/investidores/parceiros)

- Fundo Gradiente Roxo oficial em tela cheia.
- Símbolo centralizado, logo horizontal abaixo (versão branca).
- Tagline completa em Manrope Regular, branco, abaixo da logo.
- Nenhum outro elemento — capa de apresentação segue a mesma regra de "protagonista único" das demais peças.

## 6. Thumb de vídeo (capa/preview antes do play)

- Reaproveitar o **frame de capa (poster frame) do próprio App Preview**, já definido no processo de upload do App Store Connect (`docs/store/app_preview.md`) — não criar uma imagem estática separada; a consistência entre o preview real e sua capa é mais importante do que uma composição "mais bonita" isolada.
- Para uso fora das lojas (YouTube, site), usar o mesmo frame da Cena 3 do `storyboard.md` (Ranking de Restaurantes já montado) — é o momento de maior clareza de produto do vídeo inteiro.

## Pendências

- Nenhuma peça foi produzida nesta rodada — só especificação.
- Toda produção real depende das mesmas capturas de tela/vídeo já necessárias para `screenshots_spec.md`/`storyboard.md` — recomenda-se produzir tudo numa única sessão de captura, para evitar recapturar as mesmas telas repetidamente.
